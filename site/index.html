Try one photo.

Choose a photo and Tintype scores it on our server. To check more, or anything private, install it and run it yourself.

  • Photos only: one JPEG, PNG or WebP file at a time, up to 10 MB and 50 megapixels. No video.
  • From your network: 5 photos per 10 minutes, starting with your first, and 20 photos per day. The day starts at midnight UTC. People sharing a network share this allowance.

Your photo is sent in its original form, scored in memory and discarded when the result comes back: it is never written to disk or kept. The result is one statistical signal, not proof. Do not use it as the only basis for a decision about a person. Using the demo means you accept the terms of use; see the privacy notice.

The demo is not available on this copy of the page. Install Tintype to run it yourself.

From one file to a whole feed.

Install once and run inference on your own hardware. Choose the CLI for local work or serve requests from your own infrastructure.

Installation and containers ↗

Try the sample

Compare the same built-in image under two profiles. Scores summarize model evidence. Sensitive mode catches more generated images and flags more real ones.

If your shell can’t find Tintype, run export PATH="$HOME/.local/bin:$PATH" first. On Windows, open a new terminal after installing.

tintype demo --device cpu tintype demo --device cpu --sensitive

Verify the signed original

The original of the image above carries a trusted AI-generation declaration when checked with the official C2PA trust lists. The resized copy has no embedded credential.

Build from source with the optional feature. Save the signed original and the two C2PA PEM bundles in the checkout directory.

Provenance guide ↗
cargo build --release --locked --bin tintype --features provenance target/release/tintype provenance provenance-original.png \ --trust-anchors C2PA-TRUST-LIST.pem \ --tsa-anchors C2PA-TSA-TRUST-LIST.pem --json

Scan one file

Get a verdict and score for a photo or video. Add --json for structured output, or --review-margin 1 to mark results close to the threshold for review.

tintype detect photo.jpg

Process a folder

Recursively scan media and write one JSON record per file.

tintype batch --json ./media > detections.jsonl

Turbo mode

Score photos with the 8-bit CPU engine: same model and cutoffs, about 1.5–2× the throughput on Linux and Windows CPUs with an 8-bit dot-product instruction (ARM64, or x86-64 with VNNI). Its accuracy matched the standard engine on held-out photos. On Apple silicon the default GPU engine is faster.

Turbo results ↗
tintype batch --turbo --json ./media > detections.jsonl

Serve an HTTP API

Start the server, then send a file from a second terminal. The API also accepts multipart batches. Add ?mode=turbo to a request, or start the server with --turbo, for turbo mode. In Windows PowerShell, type curl.exe.

API reference ↗
tintype serve
curl --fail-with-body -F 'file=@photo.jpg' http://127.0.0.1:8080/v1/detect
