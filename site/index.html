From one file to a whole feed.

Install once and run inference on your own hardware. Choose the CLI for local work or serve requests from your own infrastructure.

Installation and containers ↗

Try the sample

Compare the same built-in image under two profiles. Scores summarize model evidence. Sensitive mode catches more generated images and flags more real ones.

If your shell can’t find Tintype, run export PATH="$HOME/.local/bin:$PATH" first.

tintype demo --device cpu tintype demo --device cpu --sensitive

Scan one file

Get a verdict and score for a photo or video. Add --json for structured output.

tintype detect photo.jpg

Process a folder

Recursively scan media and write one JSON record per file.

tintype batch --json ./media > detections.jsonl

Serve an HTTP API

Start the server, then send a file from a second terminal. The API also accepts multipart batches.

API reference ↗
tintype serve
curl --fail-with-body -F 'file=@photo.jpg' http://127.0.0.1:8080/v1/detect

Use Tintype from an agent

Install the Agent Skill after the CLI, then ask your agent to review a local photo, clip, or folder.

npx skills add cheesejaguar/tintype --skill tintype
